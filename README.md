# Energy Client Portal

Laravel client portal where companies follow their sites, electricity and gas meters, specifications and contacts.

## Features

- Companies, sites and contacts
- Electricity and gas meter records
- Specifications (cahiers des charges), scores and signatures
- Activity history and role-based access

## Tech Stack

- Laravel 10
- PHP 8
- MySQL
- Blade, Vite

## Getting Started

```bash
git clone https://github.com/ghostland-dev/energy-client-portal.git
cd energy-client-portal
composer install
npm install
cp .env.example .env && php artisan key:generate
php artisan migrate
php artisan serve
```
